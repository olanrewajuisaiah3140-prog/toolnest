ToolNest brings everyday online utilities together in one easy-to-use place. Our current tools help with PDF documents, image compression, QR codes, password creation, and text.

What we're building

Practical, straightforward utilities that work on phones and computers. We aim to keep common tasks accessible without requiring an account.

How the tools work

Some tasks, such as counting words and generating passwords, run in your browser. File-conversion and PDF processing features send files to our server to process and return the output.

A note on limitations

PDF compression may not always reduce file size, and extracting text from scanned PDFs requires OCR, which is not yet available.

Information you provide

ToolNest does not require an account. When you use PDF or image tools, you upload files for processing. Some other tools, such as the word counter and password generator, run locally in your browser.

File processing

Our current application is designed to process uploaded files in memory and return the result, rather than deliberately storing uploaded files as permanent documents. Hosting providers, proxies, operating systems, and server logs may still handle temporary data or metadata. Avoid uploading sensitive or confidential files.

Technical data

Our hosting provider may process IP addresses, request timestamps, browser details and access logs needed to deliver the service and keep it secure. Retention depends on the hosting provider's configuration.

Cookies, analytics and advertising

ToolNest's initial application code does not install analytics or advertising cookies. If we add analytics or advertising later, this page will need to explain those services, any cookies, and applicable choices or consent.

Questions or removal requests

Use the contact instructions on our Contact page. File processing happens per request; the application does not currently maintain a user account or uploaded-document library.
