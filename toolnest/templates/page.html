{% if page == 'about' %}

ToolNest brings everyday online utilities together in one easy-to-use place. Our current tools help with PDF documents, image compression, QR codes, password creation, and text.

What we're building

Practical, straightforward utilities that work on phones and computers. We aim to keep common tasks accessible without requiring an account.

How the tools work

Some tasks, such as counting words and generating passwords, run in your browser. File-conversion and PDF processing features send files to our server to process and return the output.

A note on limitations

PDF compression may not always reduce file size, and extracting text from scanned PDFs requires OCR, which is not yet available.

{% elif page == 'privacy' %}

Privacy notice: This policy explains how ToolNest handles uploaded files, technical information, and website analytics.

Information you provide

ToolNest does not require an account. When you use PDF or image tools, you upload files for processing. Some other tools, such as the word counter and password generator, run locally in your browser.

File processing

ToolNest processes uploads to produce your download. PDF compression may create temporary files on the hosting server and removes them at the end of processing. We do not intentionally keep a permanent library of uploaded documents. Hosting providers, proxies, operating systems, and server logs may still handle temporary data or metadata. Avoid uploading sensitive or confidential files.

Technical data

Our hosting provider may process IP addresses, request timestamps, browser details and access logs needed to deliver the service and keep it secure. Retention depends on the hosting provider's configuration.

Google Analytics

ToolNest uses Google Analytics 4, a website analytics service provided by Google, to understand visitor traffic, page views, and website usage. Google Analytics may collect information such as browser type, device information, approximate location, and interactions with the website.

Analytics data helps us understand which tools are useful and how to improve the website. We do not intentionally send uploaded document contents, generated passwords, or other sensitive tool inputs to Google Analytics.

Cookies, consent and advertising

Google Analytics may use cookies or similar technologies to measure website usage. Where applicable law requires consent, non-essential analytics should only be activated after the visitor has agreed. ToolNest is working on implementing the necessary consent controls.

ToolNest does not currently display third-party advertisements. If advertising services are introduced, we will update this policy to explain the relevant data practices and visitor choices.

Third-party services

Our website is hosted using Render and uses Google Analytics for traffic measurement. These service providers may process technical information in accordance with their own privacy practices.

For more information about Google's data practices, visit the Google Privacy Policy.

Questions or removal requests

Use the contact instructions on our Contact page. File processing happens per request; the application does not currently maintain a user account or uploaded-document library.
